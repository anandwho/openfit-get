Download OpenFit
On a Poco / Xiaomi pad
  1. Tap Download, then open the file.
  2. If Android blocks it: Settings → Additional settings → Privacy → Special app access → Install unknown apps → Chrome → Allow.
  3. Install over the previous version. Do not uninstall — your data stays.

After it is on the device, You → Check for update pulls the next APK from this same page. Netlify is not used.
