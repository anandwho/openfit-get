Install OpenFit

Walks, steps, sleep and phone use, tracked on your phone. Your data stays on the device and in your own cloud.

Download for Android

Installing

  1. Tap Download, then open the file from the notification.
  2. If Android asks, allow your browser to install unknown apps (Settings → Apps → Special app access → Install unknown apps).
  3. Already have OpenFit? Install over it. Don't uninstall first — your data stays.

What's new
